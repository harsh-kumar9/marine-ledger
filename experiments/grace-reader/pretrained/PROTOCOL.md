# Frozen Hugging Face readers for printed station identifiers

The prediction unit is one supplied field crop. Rank the two pretrained readers by complete identifier accuracy on Ingolf (67 fields), then by fewer character edits, then prefer the smaller English PaddleOCR reader. Use the existing stronger Tesseract single-line setting as the reference. Report both models on Challenger (31 fields) and retain the Ingolf choice even if the ranking changes. Challenger was unsealed during the earlier experiment. This comparison is retrospective. Possible overlap with upstream model training is unknown.

Use RGB pixels from the original PNG and the published image processor. PaddleOCR uses its native recognition decoder. TrOCR uses its published generation configuration with sampling disabled and a 24-new-token cap. Read one crop at a time so PaddleOCR's dynamic width is independent of neighboring examples. The reader sees only pixels. Keep the raw output, including empty strings, then apply the existing scorer's uppercase ASCII alphanumeric normalization. Use all rows. Record exact identifiers, character edits, and paired wins and losses against single-line Tesseract on Challenger.

Defer post-training if an unchanged model equals or exceeds the stronger Tesseract exact count on both reports. In that case, the next prospective experiment is transfer to a previously unseen expedition. Otherwise inspect disagreement patterns and coverage of those field types in training before deciding whether to collect labels. The criterion is a practical pilot decision on these two editions.

The two published revisions and weight hashes are frozen in [models.json](models.json). The first is a compact English recognition model for localized text. The second is an image-to-text reader trained on printed receipt lines.
