# Whole-page transfer to the Siboga expedition

Before running the reader, select the first four consecutive printed pages of numbered species accounts in M. M. Schepman, *The Prosobranchia of the Siboga Expedition*, part II (1909), in the MBLWHOI Library scan `sibogaexpeditie43sibo`. They are printed pp. 110–113 (PDF indices 7–10 inclusive when counted from zero). This offers a distinct tropical Indo-Pacific expedition, source volume and account layout. The training corpus and the completed crop test covered Pola, Albatross, Ingolf and Challenger. The other plausible source was a later Siboga monograph with crustacean accounts. Part II maintains the original pilot’s mollusc scope and opens with a station-indexed inventory.

Use all four pages, with their full printed margins, headings, comparisons, references and page numbers. Archive OCR helped locate the inventory. It did not supply the gold transcriptions. Generate grayscale PNGs by rendering the original PDF at 1800 pixels nominal width with PDFium. Freeze image bytes, selection and rights before model inference. The inference input is the page image and public page ID. Leave taxon and station tokens, target regions and enumeration counts outside the input manifest. The model worker receives no gold before predictions are committed.

The evaluator transcribes every explicit station-number mention. A marked list entry is a collection assertion when it records material obtained by the Siboga expedition under the active numbered species account. A second textual reference to an already listed station is a repeat mention of the event. A different expedition’s record or a taxonomic comparison is annotated separately. Localities and specimen counts without explicit station identifiers supply no station token. Split plural station phrases into separate mentions if present. Preserve letter suffixes and distinct mentions under different species. Pair each qualifying collection assertion with the printed species, retaining subgenus or variety in a verbatim field and genus + epithet in the normalized taxon. If a heading crosses a page boundary, limit reconstruction to the chosen pages.

The gold has one entry per marked station mention, including printed-page ID, station-token box in pixel coordinates (left/top inclusive, right/bottom exclusive), verbatim and normalized taxon, kind of mention, evidence line and containing species heading page. The collection-event key groups only repeated mentions belonging to the same taxon and station. Mark any unresolved association explicitly. Freeze the SHA-256 commitment to the complete human-readable reference before model inference, then release the file after all blind predictions are fixed. These pages estimate transfer to this one bounded source. The broader catalog check must identify expedition, date/location and taxon before it can establish a duplicate.
