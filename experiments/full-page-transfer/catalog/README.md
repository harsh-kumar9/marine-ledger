# Siboga station and voucher audit

Five surviving Naturalis lots preserve expedition station information for the four-page study. All five also have GBIF occurrences. None appeared in a GBIF search combining the resolved taxon and the word `Siboga`. Direct searches by the museum's occurrence identifiers recovered all five. Their GBIF records all lack an indexed event date, event ID and field number. A museum label changes the interpretation of one historical identification at station 164.

The inputs were the four public 1909 pages, Tesseract's blind layout and the original 1902 station register. A reviewer checked the printed taxon headings, including qualifications, and reconstructed ambiguous station strings against the register. These are independently reviewed catalog search inputs. Machine extraction scores belong to the separate blind evaluation. ## Geographic controls

On April 14, 1899 the vessel worked both 49 and 49a. The register gives 369 m for 49 and 69 m for 49a. Only 49a names Sapeh Strait. The 1909 account gives Sapeh Strait and 69 m next to a damaged superscript. On the same page of the register, 43 names Pulu Sarassa and up to 36 m, resolving a second OCR station ambiguity. [Register p4](https://archimer.ifremer.fr/doc/00000/4745/4237.pdf#page=164) · [Transcribed entries](register.json)

The unrelated positive control, *Cephalodiscus gracilis*, recovers “Siboga Stn. 89” and June 21 in both OBIS and GBIF. These are two representations of the same NIWA occurrence ID. The primary register gives June 21, 11 m and Pulu Kaniungan ketjil, with no coordinates printed. A separate Naturalis voucher confirms station 089, June 21, 11 m and locality. The NIWA record gives −0.5767, 119.1417. The preceding row 88 gives 0°34.6′ **N**, 119°08.5′ E on June 20, matching the numerical magnitudes but reversing the latitude hemisphere. The mechanism behind the modern coordinate is undetermined. The controls recover 89 and reject the neighboring station 88. ## Coverage and replay

The audit considered all 14 headings. Twelve historical species-level usages passed a WoRMS exact name and author check under the printed or an alternative combination. The Roissy attribution required a separate sensitivity query. The unidentified *Aquillus* juveniles had no species-level query. The *tuberosus* account gives a locality and provides no numbered station. The resulting 13 searchable usages cover 11 distinct accepted taxon IDs, including the disputed sensitivity mapping. A historical combination and a specimen's modern determination can differ.

For each accepted taxon, OBIS queries cover global dated records from 1899–1900 and georeferenced records from any year in 92–143° E, 13° S–12° N. A broad regional hit establishes modern catalog coverage only. Each query inspects up to 100 records. The *Distorsio reticularis* regional query inspected 100 of 102. All global expedition-year OBIS queries for the target taxa returned zero. GBIF queries cover the same years globally and, separately, the taxon plus expedition text without a date requirement. Four historical GBIF hits came from Thailand, Mauritius or New Caledonia. May omit records without normalized dates, online coordinates, linked names or indexed ship/station text; catalog and institution coverage are incomplete. The source museum queries use eleven historical and current genera, each time restricting the field being tested. Indexed dates and collecting-person searches returned zero target lots. The project-title field returned five of five, all missing an indexed start date and a structured coordinate field. The previous-source field independently located three overlapping lots in the same database. The project-title query recovered 45 records in the independent control genus. Five direct GBIF occurrence-ID lookups returned one record apiece. Undigitized material, additional genera, other project strings and missing or differently indexed terms remain outside the search. These five lots establish a lower bound. Run these commands sequentially from this directory with Python 3.9+ and curl. They replay frozen, integrity-checked JSON bytes without network access.

```sh
python3 queries.py
python3 museum.py
```

Add `--fetch` to both commands, in that order, to retrieve missing responses serially. To take a new snapshot, use a separate checkout and remove the previous request manifest and caches in that checkout first. Each `raw/<request-id>.gz` holds the original response body, including HTTP 204 empty responses. The manifest records the exact URL, HTTP status, timestamp and uncompressed SHA-256. Image rights were checked per object. All seven photographs include item metadata identifying Naturalis Biodiversity Center as owner and CC0 1.0 as license. They are provided at the original “large” rendition; OCR was unnecessary for the visual label read.
